
CyberGuard AI is a cybersecurity awareness chatbot built using C# WinForms.

Features
- GUI chatbot
- Voice greeting
- Keyword recognition
- Random cybersecurity tips
- Sentiment detection
- Memory recall
- Conversation flow
- Error handling

 Topics Covered
- Password safety
- Phishing
- Privacy
- Malware
- VPN
- Scams
