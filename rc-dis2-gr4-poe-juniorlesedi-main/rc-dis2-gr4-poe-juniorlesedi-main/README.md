# Cybersecurity Awareness Chatbot

## 📌 Description
This project is a simple cybersecurity awareness chatbot built using C#.  
It helps users learn about online safety by answering questions in a conversational way.

## 🎯 Purpose
The purpose of this chatbot is to educate users about common cyber threats and how to stay safe online.

## 💡 Features
- Voice greeting when the program starts
- User name input and personalised responses
- Answers questions about cybersecurity topics
- Handles invalid input
- Uses coloured console text and simple design

## 🔐 Cybersecurity Topics Covered
- Password safety
- - Phishing
- Suspicious links
- Online scams
- Malware and viruses
- Safe browsing
- Privacy and personal information
- Two-factor authentication (2FA)

## 🛠️ How to Run the Program
1. Open the project in Visual Studio 2022  
2. Build the solution  
3. Run the program (CTRL + F5)  
4. Enter your name  
5. Ask questions about cybersecurity  

## 📁 Project Structure
- Program.cs → Main entry point  
- Chatbot.cs → Handles chatbot logic  
- UserInterface.cs → Displays UI and design  
- VoicePlayer.cs → Plays voice greeting  

## 🔗 GitHub & CI
This project uses GitHub for version control.  
GitHub Actions is used to automatically build the project.
